# Minecraft Network

A small minecraft network setup using **Velocity + Paper**

I made this project to learn how multiple minecraft servers connect through a proxy and how the different server configurations work together

## Setup


Player
 |
Velocity
      Lobby (Paper)
      Bedwars (Paper)


Velocity is used as the proxy with the Lobby and Bedwars servers running separately on Paper

## What I configured

* Velocity proxy
* Paper backend servers
* Lobby and BedWars connections
* Server ports
* Player forwarding
* Basic server configuration
* Git / GitHub for keeping the configuration files

## Files

* `Velocity/` - Velocity proxy configuration
* `Lobby/` - Lobby server
* `Bedwars/` - BedWars server (General World- Command Orientated)

I have left out server JARs, worlds, logs and private secrets from the repository

## Why I made this

This is mainly a learning project and I wanted to understand how a Minecraft network is put together instead of just running a single paper server

I am still learning and plan to add more servers and work on database integration later even though its already done with my custom plugin
